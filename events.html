What is TechForge?

TechForge 2026 is a 48-hour hardware-software integration hackathon designed exclusively for electronics, telecommunications, and embedded systems enthusiasts. This is not a regular coding hackathon — we challenge you to build real systems that bridge the physical and digital worlds.

Whether it's a custom PCB with an FPGA, a software-defined radio transceiver, an IoT-based predictive maintenance system, or a 5G NR simulation running on edge hardware — if it involves signals, circuits, or wireless communication, it belongs here.

Team Structure & Rules

  • Team Size: 2 – 4 members per team.
  • Eligibility: Cross-branch teams are allowed, but at least one E&TC student is mandatory.
  • Deadline: All registrations must be completed by April 10, 2026.

Themes & Tracks

Embedded & IoT

Build a smart sensor node, a real-time data logger, or an interconnected mesh network utilizing edge hardware.

RF & Communication

Design an antenna, construct a modulator/demodulator pipeline, or develop a robust low-power wide-area network (LPWAN) solution.

Signal Processing

Implement active noise cancellation, real-time audio/video filtering, or advanced spectrum analysis using DSP algorithms or FPGAs.

Industry 4.0

Create a predictive maintenance system utilizing vibration and current analysis combined with Edge AI modeling.

Judging Criteria
