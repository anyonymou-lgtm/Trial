SpectrumSense

Real-time Software-Defined Radio (SDR) spectrum analyzer. We engineered a system to capture, demodulate, and visualize FM/AM signals using an RTL-SDR dongle. It successfully decodes weather satellite images (APT) and intercepts aircraft ADS-B signals.

GNU Radio Python (NumPy/SciPy) Qt5 / PyQt RTL-SDR Library Docker InfluxDB
IEEE E&TC Core Team (4 contributors)
Intermediate

EdgeIoT

An Industrial IoT gateway designed to bridge legacy hardware with the cloud. It collects temperature, vibration, and current data from PLCs/sensors via Modbus, processes it using edge machine learning algorithms, and publishes findings to AWS IoT Core. Integrated with a Grafana dashboard for real-time anomaly detection.

ESP32 / STM32 Embedded C++ FreeRTOS MQTT / Modbus TCP scikit-learn AWS IoT Core
E&TC Embedded Team (3 contributors)
Beginner

WaveGuide

An interactive electromagnetic wave propagation simulator. This web application helps visualize plane waves, reflections, and standing waves in transmission lines. Users can intuitively adjust frequency, impedance, and load parameters to observe the Standing Wave Ratio (SWR) alter in real-time.

Next.js & TypeScript Canvas API / Three.js FastAPI PostgreSQL
IEEE E&TC Lab (2 contributors)
